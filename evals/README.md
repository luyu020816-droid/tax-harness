# 真实模型留出验收 v1

`holdout-v1.json` 已冻结 40 例，L01—L10 各 4 例。每例包含明确输入、独立确定性预期和人工复核标准。不得把失败案例修改掉来提高成绩；后续新增另起版本。

配置模型后，停止隔离测试服务与 pytest，执行：

```powershell
.\.venv\Scripts\python.exe scripts/evaluate.py --output .local/evidence/live-eval-v1
```

默认每例 3 次，仅使用 `tax_harness_test`，每次重新导入比赛基线；会产生真实模型费用。可用 `--case L01-01 --runs 1` 单例排查，但不能将子集当作完整评测。未配置模型时，程序在清理测试库前退出。

报告保存实际模型 ID、参数、用量所在的上下文记录、代码指纹/提交、冻结案例指纹、逐轮输入/输出/工具、自动断言和失败记录。所有金额、保存字段、不可变字段、权限与状态断言来自独立案例预期，不以助手自述“成功”作为判据。

`automatic_pass` 只表示当前结构断言通过。每条结果的 `human_review` 初始为 pending，人工还需检查必要澄清、自然表达、规则依据、越权尝试、未完成事项和虚假保存声明。未完成人工复核时 `final_success_rate` 保持 null，不能以自动检查比例冒充最终任务成功率。

本套用于真实语言与业务回合评测，不替代 SPEC 的完整故障注入矩阵、长上下文压力测验、A/B/C 对照和正式录像。真实模型执行记录见下文。
