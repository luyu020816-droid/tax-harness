# 知识答案支持性核验：验证记录

`holdout-v1.json` 是 30 条人工标注的合成单断言样例，15 条有依据、15 条无依据。`results-v1.json` 是 2026-11-12 使用 DeepSeek V4 Flash 的一次运行记录，包含每项实际核验输出、耗时和供应商返回的 usage；数据全部为模拟内容。此集合仅评估核验器与必要的程序约束，覆盖城市、金额、单位、否定、审批例外和时间条件，**不代表完整 RAG 流程准确率，也不能证明零幻觉或生产可用**。

本次 30 条：错误通过 0，错误拒绝 0，不可用 0。标注由项目开发时人工构造，尚未经过独立专家复核；题量有限且包含相似模式，需要后续增加跨文档、复杂例外和对抗样例。结果仅是该次模型与该批样例的观察，后续模型版本可能不同。

另在独立临时数据库中用程序测试检索器和真实对话模型测试 4 个场景：南京限额和超标审批、北京追问无依据、单独新会话模糊报销问题、南京超标审批人。四次均得到与模拟资料一致的对应答复；北京没有显示南京原文卡片。**这四次使用的是确定性的测试检索器，不代表本地 BGE 的真实召回表现。**

复测：在项目根目录配置本地模型（不要提交密钥），设置 `PYTHONPATH=backend` 后执行 `python scripts/evaluate_knowledge_grounding.py`，结果写入 `.local/knowledge-grounding-eval-v1.json`。脚本仅发送本目录的合成文本，不访问或修改演示数据库；本次输出保存在 `results-v1.json`。计算费用需结合实际定价和 usage，不在此猜测。
