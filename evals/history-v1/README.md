# 冻结历史评测 v1

2026-10-30；实现者编写的公开合成消息与标注，不是用户内部数据或独立人工验收。

开发集8个家族16条语义问题、8个无答案；留出10个不同家族20条语义问题、4个无答案、6个权限/日期/抑制/水位探针，共30项。开发与留出不共享事实家族，近期无关记录使用相同公开模板。每个历史主题位于独立会话，源消息日期为2026-09-03，距本次执行超过30天；另有12条近期记录使它们落在最近窗口之外。

冻结JSON后先开发拟合历史域相关性策略，再锁定hash，最后运行留出，不套用知识域阈值。Recall@20按金标准source身份计算；另验必要原文完整保留、角色、日期、定位和hash。无答案保留候选不等于最终Agent错误回答；真实模型另测并保留人工pending。

采用实际BGE-M3与重排；精确输入的真实推理可缓存，必须记录profile和实际/缓存计数。缓存重放不是生产性能。若留出失败，保留失败，不能拿它调参后仍称独立留出。旧向量不删除的抑制反例单独验证。

fixtures.py只负责生成已写好的JSON；评测直接读取冻结JSON。没有把这些合成历史注入正式用户历史。完整100题需要与知识侧分层合并，并保留各自代码版本和已知失败，不能拼成全体Agent成功率。
