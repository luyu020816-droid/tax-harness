# ORBIT 对话工作台

开发预览：启动 `npm run dev`，打开终端显示地址下的 `/showcase.html`。
构建：`npm run build` 同时生成原入口与 `dist/showcase.html`。

新版入口复用 `App` 的身份、企业、会话、消息、停止、恢复、附件与结果组件。
中间为对话与固定输入区，右侧显示当前企业、后端任务状态、规则依据与运行记录入口。
手机隐藏右栏，任务信息仍可在任务条与消息卡片中查看。
青紫样式仅作用于新版入口。

后端沿用 Vite 配置中的 `http://127.0.0.1:8100`，需要同版本数据库和模型配置。
2026-11-01 已备份本地数据库并从迁移 1–3 升级至 1–9，完成一次真实模型月度查询联调。
金额与数据库直接汇总一致，历史恢复、刷新后的运行追溯和多尺寸布局通过。
记录及边界见 `../docs/ORBIT_INTEGRATION_20261101.md`。
后续升级数据库前仍须备份并检查迁移影响，尤其是迁移 004 对未完成任务的中断处理。

浏览器回归：设置 `UI_BASE_URL` 为本地 Vite 地址，运行 `npx playwright test tests/orbit.spec.ts`。
测试明确使用接口夹具，覆盖失败保留草稿、幂等重试、中文输入法、轮询、历史恢复、新会话和多尺寸布局。
`orbit-chat-*.png` 为该测试生成的截图，页面上的“程序测试模式”标识说明它们不是实际模型办理证据。
