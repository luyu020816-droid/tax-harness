# 运行洞察使用说明

运行洞察是原运行记录Tab的升级，不需要额外观测平台或Embedding Key。正常启动现有服务即可；旧数据库先增量迁移010，不运行样例重导。

## 启动与迁移

在仓库根目录按既有说明配置`.env`并启动数据库。旧库升级在备份后执行：

```powershell
$env:PYTHONPATH = 'backend'
.\.venv\Scripts\python.exe scripts/migrate_insights.py --output .local/backups/insights-your-date
```

目标目录须为新目录。脚本验证归档目录可读、增量迁移、角色授权与业务字段指纹；不等于完成整个备份恢复演练。迁移失败先检查报告，不重置业务库。随后从backend目录启动既有`uvicorn app.main:app`。ready包含迁移10检查。

## 计量字段

| 字段 | 含义与限制 |
|---|---|
| 请求数 | 筛选范围内有权限的turn数；恢复不算新请求 |
| 完成比例 | completed/终结请求；等待补充另列，不代表答对率 |
| 活跃执行 | 可证明的执行区间并集；崩溃接管的未知结束不能补造成完整耗时 |
| 请求历时/首排队 | 受理至结束与首执行等待；不等于纯模型等待 |
| 已知Token | 供应商返回的有效prompt/completion usage；缺失另计，不补0 |
| 输入构成 | 实际payload的UTF-8估算分区；不是供应商实际usage |
| 费用估算 | 显式价格与有效usage推导；缓存明细缺失时标上界估算；不同币种不混加 |
| 采集覆盖率 | 已知usage/耗时/发送状态的覆盖情况；旧数据无法补采的不猜测 |
| 已执行交付 | 工具成功与final_cards的交付关系；用户完整意图覆盖仍为未核验 |

列表默认最近7天、按上海日期，最大31天；列表最多50项，节点每页100项，原始内容每块32KiB，JSON导出最多10MiB。分页固定高水位，授权和失效仍按读取时检查。页面隐藏/离开取消读取，查看与导出不恢复任务，不调用模型，不写业务。

## 可选价格登记

默认`.local/insight-prices.json`，也可用`INSIGHT_PRICE_FILE`指定本地路径。未配置时显示待计价，不需要为验收编造价格。文件是JSON数组，每项只登记经过人工核对的供应商报价，字段如下：

| 字段 | 类型 |
|---|---|
| model | 完整、精确匹配实际响应的模型标识，无别名推断 |
| currency | 报价币种字符串 |
| as_of | ISO日期，例如报价核实日 |
| source | 实际报价来源说明或链接 |
| input_cache_hit_per_million | 每百万输入缓存命中价格，非负有限十进制**字符串** |
| input_cache_miss_per_million | 每百万输入未命中价格，十进制字符串 |
| output_per_million | 每百万输出价格，十进制字符串 |

超过64KiB、格式错误或模型不匹配都按未知处理。新计量在调用时捕获价格快照，包括当时未配置的状态，未来改文件不会追改这些调用。旧记录无快照时可按明确登记价格归一估算，页面标明这是历史归一价。当前没有经过核实的v4登记价格，因此本轮费用为未知；旧对比报告使用其独立固定报价，二者分开。

## 本地评测导入

```powershell
$env:PYTHONPATH = 'backend'
.\.venv\Scripts\python.exe scripts/import_insight_evaluation.py --help
```

仅维护者从可信本地JSON导入，设置owner与实际企业范围。支持已有advanced比较报告，校验格式、重新核算数值、按哈希去重，不导入原始Prompt到对比页面。页面策略对比只读；开发集不是留出集，缺少可比条件不显示因果胜负。

## 排错与隐私

- 旧记录无计时/usage、来源无法验证、价格未知是明确的数据状态，不能靠刷新补出历史事实。
- 权限撤回会隐藏涉及该企业的整个请求；来源或偏好失效会保护旧原始输入，旧详情和导出同样受限。
- 计量写入采用有界独立事务，失败日志为固定错误名；业务审计和保存守卫仍照常执行。
- 本机`.local`包含日志、备份、截图和可能的原始业务证据，不提交到GitHub。对外材料使用白名单脱敏摘要。
- 遇到真实卡顿、超时或明显退化再定位；1秒附近差别不作为额外优化理由。报告需附样本量、候选指纹与环境。
