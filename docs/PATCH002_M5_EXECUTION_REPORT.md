## 实现结果

过去消息仍以数据库Source原文为真值，新增派生历史分块、1024维BGE索引、持久索引任务、查询及引用。原文保存与任务排队同事务；索引租约、fencing和发布前revision/hash核验阻止迟到任务发布。向量失败保留原话，不能影响正式任务、显式偏好和业务账本。

检索先限制本人、明确企业、时间、当前修订和读取水位，再进行词法/向量候选、RRF与真实重排。历史域阈值独立开发校准，不套用知识域阈值。模型改写只作补查，宿主先查询真实当前用户问题；已有有效片段在partial状态仍允许引用，不能因其他索引缺口漏掉已找到的原文。

日期浏览不依赖向量，最多31天窗口、每页5条，绑定会话/身份/范围/水位的游标连续翻页，宿主生成整页与末页提示。长消息可通过read_history逐段完整读取。聊天导航只取已完成回复实际发布的页面与引用，不把未展示的后台查询当作当前页。

历史引用显示发生时间、角色和企业，持久保存citation及Unicode字符位置，前端定期重验；更正、删除或撤权后撤下正文。助手当年的“已保存”只是历史文字，当前业务值必须重新查询。联合企业历史必须明确指定并逐项核权，不能把多企业工具回包复制成个人私有来源。
