## 交付内容

1. `RequestFrame / ScopeBinding`：当前来源修订、接收时间、企业及月度引用。支持明确更正、相对日期、已确认年份的月份补充与连续复用；拒绝猜测月份、跨轮引用和用待澄清事项洗白月份。
2. `WritePlan`：冻结企业、票号、purpose/note patch、发票revision、来源、规则与有效列表。有限完整语法核对直接授权；不充分匹配则由本人确认；否定、假设和纯引文不能直接写。
3. 确认/撤销HTTP与前端：展示前后值、过期/撤销状态，重复确认复用同一控制轮次。本人确认由程序执行冻结计划，成功后关闭原待确认事项。原有界面风格保留。
4. 核心保存仍使用现有账本：无计划不能直写；invoice、operation、计划消费和任务进度同事务；重复执行不增加第二次业务版本；旧操作可按原编号只读核验。
5. `AnswerPlan / AnswerRenderer`：模型只选真实结果引用、操作、历史引文和说明code；程序渲染金额、总数、保存状态、规则及必要追问。纯澄清可无结果块，空白完成和任意message不能交付。
6. 回执区分未保存、状态未确定、待核验、无变化、已核验及后来变化；规则视图直接说明1000元含边界和备注不能代替用途。
7. 历史检索增加本轮之前的来源序号边界，避免反复召回当前提问与自己的工具输出。这仍是现有文字检索，不是语义RAG。
8. schema 4、部署切换说明与真实旧schema迁移测试；旧在途轮次中断并增加围栏，正式状态及原文保留。备份快照自动覆盖新增表。

模块职责、接口样例及迁移步骤见[办理协议与模块边界](PATCH002_CONTRACTS.md)。
