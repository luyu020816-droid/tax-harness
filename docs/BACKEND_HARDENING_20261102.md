| 配置 | 默认值 | 范围 |

| LOGIN_TTL_SECONDS | 43200 | 登录有效期，最大86400秒 |
| REQUESTS_PER_MINUTE | 60 | 每用户新请求及恢复请求的滚动分钟窗口 |

| MAX_PENDING_GLOBAL | 200 | 同库全局queued/running轮次 |

| STATEMENT_TIMEOUT_MS | 15000 | 新建应用连接的语句等待上限 |
