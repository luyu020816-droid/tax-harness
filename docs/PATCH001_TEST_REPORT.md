## 已验证的具体断言

- 新票追加后金额/数量进入真实业务查询，前导零编号可用；旧用途/备注遇到空输入保留，非空差异和金额差异进入冲突。
- 文件内相同记录折叠、同键不同值整组冲突；默认问题批次不能确认，显式 skip_issues 后只提交候选新增集合。
- 重复上传请求幂等、同请求不同内容拒绝；同批次重试/同时确认返回相同回执，只插入一次、只增加一次数据版本；不同批次并发含同票只有一个提交，另一个预览过期。
- 提交中注入账本失败，发票、company head 和批次状态全部回滚；令牌伪造/过期、旧 revision、计划值被篡改均拒绝。
- U002 不能导入、不能读取 U001 文件/批次；预览后撤销导入权不能确认；跨企业/会话不能使用原确认；比赛实例拒绝导入。
- 运行角色不能 INSERT 发票；入库角色不能 UPDATE 发票、写银行表或在比赛库取得新增能力；比赛与扩展实例登录 Cookie 不相互覆盖。
- 非法编号/日期/金额/字段类型、公式、宏类型、异常 ZIP、超文件限制、非模板列和额外业务工作表拒绝；有问题时不返回“零条成功”。
- 先形成有效任务检查快照，再导入，旧任务变为 snapshot_current=false 且 task_evidence 不注入；当前重查缺项从 5 变 6。U002 无任务的模型正在生成时，U001 导入后其旧企业输入答复被中断。
- 附件进入实际上下文的受控身份与 manifest；模型无提交工具、不取得确认令牌。测试适配器强行尝试写偏好被程序拒绝，不能据此声称已证明真实模型抵抗所有文件诱导。
- BYTEA 原文件、账本与发票经过真实 pg_dump/restore 后指纹一致；大批次完整行回执保留数据库，接口/模型输出明细每页不超过 20 行。

Chrome 验证无模型上传/预览/确认、数据库真实新增、已提交回执、导入历史、冲突阻止和明确跳过、Esc、360px 无页面横向溢出、切换只读用户隐藏入口、浏览器无 pageerror。截图在 `.local/evidence/import`；已人工查看桌面和 360px 预览，状态、计数与主要确认操作清晰。
