## 八项逐项核验

1. **Agent 管理**：核对配置创建、发布、启停、模型和提示词绑定、工具权限与请求版本边界。程序证据包括 `test_agent_profiles.py`、`test_agent_admin_api.py`、`test_agent_models_db.py`、`test_agent_runtime.py`；真实后端页面 `agent-backend-live.spec.ts` 已通过创建、发布、选用 Agent 与查询轨迹流程，生成输出使用脚本模型。真实模型下的职责遵循仍需专项验证。

2. **能力组织与复用**：核对多个 Skill 组合、直接授权与 Skill 授权并存、共享能力、多 Agent 复用、能力版本和停用后权限。对应 `test_agent_acceptance_1117.py`、`test_agent_capabilities.py`、`test_agent_authority.py`、`test_agent_knowledge.py`。页面配置与并发编辑检查已通过；复杂现场任务中的自主组合效果仍不能由配置测试替代。

3. **多轮办理**：核对缺失信息、局部字段更新、字段清除、多待办保留、取消与权限边界，对应 `test_memory.py`、`test_conversation_semantics.py`、`test_conversation_evaluations.py`、`test_request_checklist.py` 等。页面请求清单、历史会话、身份切换检查已通过。自然语言歧义下的真实模型追问和局部更正仍需补验。

4. **长期记忆**：核对跨会话读写、修订/删除、墓碑和旧源防复活、冲突覆盖、企业与个人隔离、旧摘要和轨迹中的失效内容抑制，对应 `test_memory.py`、`test_phase_two.py`、`test_faults.py`、`test_recovery.py` 等。真实后端页面已通过偏好新增、删除与修订检查。真实模型跨重启的自然语言回忆效果仍需补验。

5. **知识库策略**：核对策略版本、范围和权限、资料新增/新版生效/停用、旧引用失效、业务日期与溯源，对应 `test_phase_two.py`、`test_knowledge.py`、`test_knowledge_file_lifecycle.py`。真实后端页面策略发布已通过；真实本地 BGE 向量检索和重排的三条改写问题全部命中正确审批制度，详见 `retrieval.json`。这三条样例不足以代表广泛召回率，最终生成答案的真实模型效果仍需补验。

6. **文件处理**：真实原入口上传 XLSX、DOCX、文字型 PDF，等待处理发布，并从详情页下载原件逐字节比较，三项均通过。程序测试另覆盖定位、版本、重复上传、私有资料与越权、金额/日期/币种守卫、工作簿只读查询。小样例上传成功不能证明所有复杂财税文件计算准确；复杂多表计算与真实模型引用质量仍需专项验证。

7. **上下文管理**：核对预算、自动和手动压缩、关键对象/约束/待办保留、跨 Agent 摘要隔离、失效依据排除、历史和文件原文回溯，证据见 `test_context_limits.py`、`test_context_compaction_flow.py`、`test_compaction.py`、`test_compaction_batches.py`、`test_agent_context.py` 等。页面上下文用量及真实后端压缩入口已验证；短会话可能返回无需压缩，不能当作长对话压缩效果的证明。真实模型长对话和大文件综合效果待验。

8. **异常恢复**：核对超时/连续错误、丢失响应、租约重领、重复请求幂等、已完成工具结果保留、待确认操作不自动执行、持久化恢复与真实状态展示，证据见 `test_faults.py`、`test_recovery.py`、`test_runtime.py`、`test_budget_query_recovery.py` 等；页面网络错误、未知提交状态、显式继续、刷新恢复检查已通过。不能用模拟故障替代真实部署进程被杀及外部模型网络故障的全部现场表现。

## 已确认的问题

**P2：窄屏运行洞察不能返回历史记录。** 打开运行洞察并选中请求，将视口依次调整到 1440、1024、768、390、360px 后，正常点击“返回历史记录”持续被上层容器拦截。修正无关的 Agent 列表模拟后，单独运行仍复现。定位入口：`frontend/src/InsightTrace.tsx` 的 `insight-back` 按钮，相关布局在 `frontend/src/insights.css`。根因尚未确认，不应仅提高 z-index 或强制点击掩盖问题。此问题影响窄屏轨迹浏览，不能据此判定八项后端能力均不合格。

复现：`UI_BASE_URL=http://127.0.0.1:8197 npx playwright test tests/insights.spec.ts --reporter=line --timeout=30000`（需要先构建并提供前端静态服务）。保留了失败截图、页面快照和 trace。
