后端验证包括：四组官方金额；成功无记录；两企业 9 月规则差异、1000 边界、空白和备注；运行角色不可改金额/银行表；U002 权限；双字段保存；同来源意图唯一和旧 revision 重试；任务与业务原子回滚；已提交但回读不可用；较晚修改不假报核验成功；错误票号/无列表序号拒绝；保存后缺项由 5 变 4；任务唯一性、修订与跨会话；全局/企业偏好；更正删除与旧来源重放；窗口以外查原文；模型在途删除和取消围栏；必要输入超预算拒绝；实际 payload 与 manifest 一致；摘要处理缺口、错误候选、在途 epoch 变化；闭合工具协议；一致备份恢复；旧备份缺少删除记录时关闭业务和记忆接口；旧回执本身落后时拒绝覆盖当前数据，且不能用旧回执解除维护。

另已验证：真实连接池重建后处理已受理 outbox；过期租约被接管后旧执行拒绝提交且已保存操作只核验；同一旧偏好版本并发更正仅一方成功；索引表不可用时正式状态仍可读；索引重建不复活删除；处理水位保留早期缺口；源内容校验失败时不发送输入；规则版本启用/停用改变当前检查；任意自然语言规则保持草稿。

程序循环通过明确的 ScriptedModel 驱动，验证工具、状态与真实数据库的连接。**这些结果不证明真实模型理解质量、总体任务成功率或比赛获奖概率。**

Chrome 覆盖：模拟登录；金额卡片；用途清单；保存复查；偏好新增/更正/删除；运行详情与实际输入折叠项；Esc 关闭；1280/768/390/360 宽度无整体横向溢出；中文组合输入 Enter 不发出请求；企业切换清空旧工作区；U002 只读且不显示旧用户结果。SSE 中断后的轮询已经实现，但断线故障未计为浏览器已验收。
