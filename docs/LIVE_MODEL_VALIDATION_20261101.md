## 新发现的稳定性问题

`A01-summary-3` 中，模型将来源返回为 `[["s1"],["s2"]]`。当前兼容逻辑仅接受已验证的一种单列表包裹，不接受这种多个内层数组的形状，因此抛出 `SUMMARY_INVALID`，没有发布候选。

该次仅摘要方案未提供所需事实；原始资料没有删除，也没有因此产生错误保存。本次摘要加检索样例没有出现此格式失败。它仍是值得优化的结构化输出稳定性问题，不能因为默认策略本轮 18/18 就称为已解决。原始响应和失败断言完整保留，未临时放宽格式或修改预期来提高通过率。
