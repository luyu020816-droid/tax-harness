## 已实现

- 原工作台提供 Agent 管理、Agent 选择和运行详情。管理者可创建草稿、发布版本、启停 Agent，配置模型、工具动作、Skill 和知识范围；资料列表支持继续加载后续页面。非管理用户不能调用管理接口。
- 工具由已有实现复用。模型输入按授权筛选工具，执行与发票确认时重新检查；全局停用同时约束旧助手入口，别名按实际目标授权。受限知识范围额外限制检索、引用和历史上下文，不扩大用户／企业原有权限。
- Agent 请求绑定不可变配置快照；撤权与业务提交使用同一事务锁协调，已提交的业务回执保留。Skill 单独发布版本，依赖必须显式授权。能力及配置变化记录事件。
- 模型配置支持单独测试、失败保留旧配置、版本绑定。页面输入的密钥仅在进程中保存；重启后需重新测试并重新发布引用新版本的 Agent。默认模型继续使用现有环境配置。
- 新增迁移 017—023；初始化时在无已有 Agent／Skill 配置的情况下创建两个示例 Agent 和一个共享 Skill，保留已有用户配置。新代码需要数据库迁移至 023；**本轮没有升级或重置现有业务库**。
