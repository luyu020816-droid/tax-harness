## 当前行为

- 普通聊天保留会话记录与业务来源，不再自动写入history_index或创建history_jobs。
- 模型不暴露search_history/read_history；旧调用、HTTP历史搜索和后台回填明确拒绝。旧.env打开历史开关也不能恢复这些线上入口。旧算法保留，未执行大规模删除。
- 会话内最近上下文保留；摘要生成、累积、替换和加载按session_id隔离，逐条验证来源属于当前会话。当前摘要的精确引用回读同时核对会话与权限，不进行跨会话搜索。
- 对其他会话内容的提问明确说明边界，不声称过去没有说过、不凭空猜测。
- 文件上传与新“添加文字”入口共用知识接入/解析/索引链路。聊天中的文字入库要求只产生草稿，点击卡片核对并提交才真正写入；提交和索引就绪分开显示，重复请求幂等。
- 模型生成草稿后不能只用“未修改”说明结束。交付守卫从持久工具账本检查草稿卡片；缺少卡片拒绝答复并给实际结果视图反馈。
- 会话支持置顶/取消置顶、归档/找回、删除和完整分页历史。运行中的会话禁止归档/删除；归档会话先取消归档再发送。已删除会话不能继续发送或重试，相关会话摘要退出使用。
- 删除会话不连带删除手动知识资料、发票、任务、明确偏好或操作账本；审计保留不等于物理擦除所有原文。

## 页面入口

打开 `http://127.0.0.1:8105/showcase.html`，必要时Ctrl+F5。

1. 左侧最近会话每行“…”：置顶、归档、删除。“全部会话与归档”可查看前8条之外的记录。平板收起侧栏时使用历史图标入口。
2. “知识资料”→“添加文字”：选择当前企业后填写标题、正文，手动提交。
3. 对话明确要求把文字加入知识库：查看待提交草稿，点击“核对并提交”；草稿本身不可检索。
4. “运行洞察”：查看同一请求的工具、模型输入与耗时。旧历史对比只作为已导入实验报告，不自动执行历史检索或重跑收费模型。
